# Terra Industries — prototyp 0.1

Pierwszy fundament oryginalnej gry 3D o eksploracji i automatyzacji przemysłowej.

## Aktualne funkcje
- scena 3D z terenem i oświetleniem;
- postać gracza i kamera trzecioosobowa;
- sterowanie WASD, strzałkami oraz przyciskami dotykowymi;
- pole rudy żelaza;
- interakcja: podejdź do złoża i naciśnij E, aby zebrać jednostkę rudy.

## Uruchomienie
Wymaga Node.js 20+:
```bash
npm install
npm run dev
```

## Plan rozwoju
1. ekwipunek i zasoby;
2. budowanie na siatce;
3. automatyczna koparka;
4. taśmociąg;
5. piec i sztabki żelaza;
6. energia, zapisy i optymalizacja mobilna.

To wczesny prototyp techniczny, a nie ukończona gra.
